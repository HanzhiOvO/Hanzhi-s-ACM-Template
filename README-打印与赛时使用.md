# 一只奶龙 - XCPC 2026 算法模板（字体优化最终版）

## 打印建议

- 纸张：A4。
- 推荐：双面打印、长边翻页。
- 彩印效果最佳；黑白打印仍可通过标题条、灰度和字体层级区分重点。
- 打印店建议选择“实际大小 / 100%”或标准 A4，不要二次裁切、重排版或强制缩放。
- 正文保留装订安全边距；如采用较宽打孔，先试印 2-3 页确认孔位。

## 这版字体体系

- 中文正文：清晰的印刷宋体，适合长时间纸面阅读。
- 章节 / 小节 / 目录主层级：楷体，保留个人笔记感，同时强化视觉层级。
- C++ 代码：Noto Sans Mono；关键字使用半粗体，字母和数字在小字号打印下更清楚。
- 行内 API / 标识符：使用等宽字体，和正文一眼区分。
- 原封面完全保留，不改动原视觉风格。

## 赛时阅读顺序

`赛时先看 -> 不会用就照抄 -> API / 入口函数 -> 核心逻辑 -> 关键量 -> 完整实现`

已经判断出算法时，不要先读内部递归实现；优先照公开 wrapper 接入 `solve()`。
