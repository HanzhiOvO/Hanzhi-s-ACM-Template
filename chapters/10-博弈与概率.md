## 10 博弈与概率

### 10.1 SG 函数（组合博弈）

> **简介**：公平组合游戏（双方同操作集合）：状态 SG = mex(后继 SG)，异或和为 0 则先手必败。所有"轮流操作、不能动者输"的题通用。
>
> **快速识别**：轮流取/移动、无随机、不能操作者输；多堆/多子游戏（异或和）。
>
> **API 接入**：
> - `sg[状态] = mex({sg[后继]})`；记忆化 DFS。
> - 多子游戏：总 SG = 各子 SG 异或；非 0 先手胜。
> - 打表找规律（周期/公式）后 O(1)。
>
> **关键点**：**mex = 最小未出现非负整数**；SG 只对"公平"游戏适用（双方同操作）；打表是常态——先暴力小范围找 SG 规律；必胜步 = 找一个后继使异或和为 0。

```cpp
// 记忆化 SG（例：一堆石子，每次取 1 或 2 个，取完者胜）
int sg[1001];
int get_sg(int x) {
    if (sg[x] != -1) return sg[x];
    set<int> s;
    for (int take : {1, 2}) if (x >= take) s.insert(get_sg(x - take));
    int g = 0;
    while (s.count(g)) ++g;
    return sg[x] = g;
}
// 多堆：ans = xor of sg[每堆]；ans != 0 先手胜
```

### 10.2 Nim 家族速查

> **简介**：经典 Nim（异或和判胜负）及变体：Misere Nim、阶梯 Nim、Fibonacci Nim、Wythoff、Moore's Nim-k、树上删边（Green Hackenbush）。
>
> **快速识别**：取石子/取物类博弈题：先识别是哪一族（数量、取法限制、胜负条件），再套结论。
>
> **API 接入**：
> - 标准 Nim：`xor = a[0]^a[1]^...`；非 0 先手胜；必胜一步：找堆使 `a[i] > (a[i] ^ xor)`，改成 `a[i] ^ xor`。
> - Misere Nim（取最后一个输）：全为 1 时看奇偶；否则同标准 Nim。
> - 阶梯 Nim（只能从奇数层取）：只看奇数层异或。
> - Fibonacci Nim（首取任意、之后不超过上次两倍）：先手胜当且仅当 n 不是 Fibonacci 数。
> - Wythoff（两堆，可取任一堆任意个或两堆同数）：`|a-b| * 黄金比 == min(a,b)` 则必败。
> - Moore's Nim-k（一次最多动 k 堆）：二进制每位和 mod (k+1) 判。
>
> **关键点**：**先确认变体再套结论**（Misere 与标准只差全 1 特判）；阶梯 Nim 只算奇数层；Wythoff 用浮点黄金比注意精度（用整数近似或 long double）；树上删边 = 每条链长度异或（Colon 原理）。

```cpp
// 标准 Nim 必胜一步：
// int xr = 0; for (int x : a) xr ^= x;
// if (xr == 0) 先手必败;
// for (int &x : a) if ((x ^ xr) < x) { x = x ^ xr; break; }  // 输出必胜操作
// Fibonacci Nim：n 是 Fibonacci 数 => 必败
// Wythoff：a <= b，(b - a) * (1+sqrt(5))/2 == a（浮点容差）=> 必败
```

### 10.3 随机算法（爬山 / 模拟退火 / 随机化）

> **简介**：近似/概率算法：爬山（邻域贪心）、模拟退火（接受劣解跳出局部最优）、随机打乱/随机化哈希（防构造数据）。
>
> **快速识别**：几何最优（费马点、最小圆）、连续最优化（答案精度要求不高）；构造数据针对性卡时用随机化。
>
> **API 接入**：
> - 爬山：`for 迭代: for 方向: 尝试移动，接受更优`。
> - 模拟退火：`T` 从高到低，接受概率 `exp(-delta/T)`；多次重启取最优。
> - 随机化哈希：给每个元素随机权值（splitmix64），集合哈希 = 异或/和。
>
> **关键点**：模拟退火参数（初始温度、降温率、迭代次数）要调；**多次运行取最优**；随机化哈希防碰撞要 64 位随机；期望得分而非保证 AC——只有确定算法超时才用。

### 10.4.1 超现实数博弈（Surreal Number，2024 ICPC 南京 D）

> **简介**：部分博弈的形势可表示为**超现实数** `{L | R}`（L = 左方一步可达的形势集，R = 右方）。当 L 中所有元素 < R 中所有元素时，该形势是"数"，其值为 L、R 之间的**最简单数**（分母为 2 的幂的二进制分数）。多个游戏的**和 = 各数相加**；值 > 0 左方（先手）必胜，< 0 右方必胜，= 0 后手必胜。SG 只能处理"取石子"型公正博弈，超现实数是**带偏向（左右不对称）博弈**的通法。
>
> **快速识别**：博弈双方**可选操作不对称**（如 2024 南京 D：两人交替落子棋盘，各自的合法格不同）；"形势价值"可递归定义且子形势构成偏序；SG 推不动（左右策略不同）。
>
> **API 接入**：
> - `Surreal(m, e)`：值 = m / 2^e（二进制分数，m 为奇数或 0 时是**最简形式**）。
> - `Surreal::simplest_between(L, R)`：`{L | R}` 的值（要求 L < R；不满足则不是数，需转 SG/超现实游戏和）。
> - `cmp` / `operator+`：比较与加法（精确，无浮点误差）。
> - 判定：值为正 → 左方必胜；为负 → 右方必胜；为 0 → 后手必胜。
>
> **关键点**：**只有 L < R 时才是数**；多个独立游戏**先各自求值再相加**；值域编码 (m, e) 保证精确（1/2、3/4 等二进制分数），e 到 60 足够竞赛；n 大时值会指数级分层，**e 增长快，只用于小形势**；负数 floor 除法用 `div_floor`（向负无穷）。
>
> **依赖**：无（自包含）。

```cpp
// 超现实数：值 = m / 2^e（e 可为负=整数放大；m 奇数或 0 为最简形式）
// 2024 ICPC 南京 D：局面 {L|R} 为数的条件 L < R，值 = simplest_between(L, R)
// 多个子游戏之和 = 各值相加；值>0 左必胜，<0 右必胜，=0 后手必胜
struct Surreal {
    i64 m; int e;                                  // 值 = m / 2^e
    Surreal(i64 m_ = 0, int e_ = 0) : m(m_), e(e_) { norm(); }
    void norm() {                                  // 约去 2 因子到最简（m=0 时 e=0）
        if (m == 0) { e = 0; return; }
        while (e > 0 && m % 2 == 0) { m /= 2; --e; }
    }
    // 精确比较：通分到 2^max(e) 的整数域（i128 防溢出）
    int cmp(const Surreal& o) const {
        int ne = max(e, o.e);
        i128 a = ((i128)m) << (ne - e);
        i128 b = ((i128)o.m) << (ne - o.e);
        return a < b ? -1 : a > b ? 1 : 0;
    }
    bool operator<(const Surreal& o) const { return cmp(o) < 0; }
    bool operator==(const Surreal& o) const { return cmp(o) == 0; }
    bool operator>(const Surreal& o) const { return cmp(o) > 0; }
    Surreal operator+(const Surreal& o) const {
        int ne = max(e, o.e);
        i128 a = ((i128)m) << (ne - e), b = ((i128)o.m) << (ne - o.e);
        return Surreal((i64)(a + b), ne);          // 值域小（竞赛形势）不会溢出
    }
    // 向负无穷整除：floor(a / b)，b 为 2 的幂（移位）
    static i64 div_floor(i64 a, i64 b) {
        if (a >= 0) return a / b;
        return -((-a + b - 1) / b);
    }
    // {L | R} 的最简单数：要求 L < R；返回值 m/2^e（e 最小、m 使 L < v < R）
    static Surreal simplest_between(Surreal L, Surreal R) {
        if (L.cmp(Surreal(0)) < 0 && Surreal(0).cmp(R) < 0) return Surreal(0);
        for (int e = 0; e <= 60; ++e) {
            // 候选 v = m / 2^e，m 需满足 L*2^e < m < R*2^e 的最小整数 m
            i128 lo = val_scaled(L, e), hi = val_scaled(R, e);
            i64 m0 = (i64)(lo + 1);                // m 下界 = floor(L*2^e) + 1
            if (m0 < hi) return Surreal(m0, e);    // 存在整数 m 即最小 e 的答案
        }
        return Surreal(0);                         // 不可达（不会发生）
    }
    // 精确计算 x * 2^e 的上下界（返回值保证 floor 精度）
    static i128 val_scaled(const Surreal& x, int e) {
        if (e >= x.e) return ((i128)x.m) << (e - x.e);
        i64 b = (i64)1 << (x.e - e);
        return (i128)div_floor(x.m, b);            // 向下取整
    }
};
```
